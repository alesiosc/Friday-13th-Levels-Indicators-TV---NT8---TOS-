## **HOW TO RUN - NinjaTrader 8 Levels Indicator**

### **Overview**
This project contains a NinjaTrader 8 indicator that has been converted from a Pine Script indicator. The indicator provides support and resistance levels for NQ and ES futures contracts with multiple sets of levels and configurations.

### **Prerequisites**
- NinjaTrader 8 installed on your system
- Development environment to compile custom indicators

### **Setup Instructions**
1. Copy `src/NT8_Levels_Indicator.cs` to `Documents\NinjaTrader 8\bin\Custom\Indicators\`
2. Open NinjaTrader 8 and press F5 to compile
3. Add the indicator to your chart
4. Configure the NQ and ES data inputs according to your requirements
5. Adjust styling options as desired

### **Configuration Options**

#### **Global Settings**
- **Label Anchor Position**: Left (default) or Right - determines which edge labels anchor to when resizing (2026-01-13)

#### **Data Inputs**
- **NQ and ES Data Inputs**: Separate configuration for both NQ and ES contracts
- **Set 1-4**: Four different sets of levels with different styling options
- **LIS Levels**: Special institutional support levels

#### **Styling Options**
- **Colors, sizes, opacities, and line styles** for all elements
- **Label Bold/Italic**: Each set has bold and italic toggles
- **Label X Offset**: Horizontal offset (bars from anchor edge) for all sets (2026-01-13)
- **Line Width/Style**: Configurable for all sets including Set 1 (2026-01-13)

### **Important Notes**
- The indicator only draws on the last bar
- All drawing objects are cleared and redrawn on each bar update
- Label overlapping is prevented with offset tracking
- Labels stay anchored to the selected edge (Left or Right) when resizing the chart window
